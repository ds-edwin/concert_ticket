티켓 발급 서버 연결 업데이트

웹사이트가 발급 결과를 직접 받을 수 있도록, 기존 Apps Script에 아래 함수를 추가합니다.

  1. 현재 티켓관리 시트의 확장 프로그램 → Apps Script를 엽니다.
  2. 왼쪽 파일 + → 스크립트를 눌러 HTTP라는 파일을 만들고 아래 코드를 붙여 넣습니다. 새 파일의 기본 코드는 지운 뒤 붙여 넣고 저장하세요.
  3. 배포 → 배포 관리 → 기존 웹 앱 선택 → 연필 아이콘 → 버전: 새 버전 → 배포를 누릅니다.

기존 배포를 수정하므로 웹 앱 URL과 기존 티켓 번호는 그대로입니다. setup은 다시 실행할 필요가 없습니다. 이미 doPost 함수를 추가했다면 같은 함수를 중복으로 넣지 마세요.

배포 후 확인

이 검사는 서버 버전만 확인하며 티켓을 발급하지 않습니다.
